# 0001. Fork h16nning/skola under AGPL-3.0

Date: 2026-11-01
Status: Accepted

## Context
We need a mature local-first flashcard app (rich text, cloze, decks, Dexie storage) instead of building one from scratch.

## Decision
Fork h16nning/skola and keep its AGPL-3.0 license. MIT code may be copied; unlicensed code is ideas only.

## Consequences
A publicly run modified version must publish its source. We inherit upstream a11y lint warnings (tolerated).
